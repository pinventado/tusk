# TUSK
## Titan Unix/Linux Starter Kit
This repository builds and publishes the CSUF TUSK-based Ubuntu teaching image. It is a focused image-builder fork that keeps only the files needed to define the package set, bootstrap the image, and publish it to GitHub Container Registry.

The project is an evolution from msgfxkit and [Tuffix](https://github.com/kevinwortman/tuffix) so a debt of gratitude is due especially to Kevin Wortman, Paul Inventado, Luis Larco, and Kenyt Avery.
